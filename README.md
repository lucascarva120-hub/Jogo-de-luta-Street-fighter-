# Jogo-de-luta-Street-fighter-
Jogo de luta
🥊 Street Fighter JS — Engine de Jogos de Luta 2D

Um protótipo de jogo de luta estilo arcade desenvolvido em JavaScript puro, criado como projeto de TCC do curso Técnico em Desenvolvimento de Sistemas.

O objetivo principal do projeto é demonstrar conceitos fundamentais de desenvolvimento de jogos, incluindo:

Física em tempo real
Gerenciamento de estados
Sistema de colisão (Hitbox)
Game Loop
Manipulação gráfica com Canvas
Interface dinâmica
🎮 Demonstração do Projeto

O jogo simula batalhas 1v1 inspiradas em clássicos como:

Street Fighter II
The King of Fighters
Mortal Kombat

Os jogadores podem se movimentar, pular e atacar em tempo real, com detecção precisa de colisões e atualização dinâmica da interface.

Microsoft Edge
